# プロジェクト画面からのタスク追加

プロジェクト画面のタスク一覧からタスクを追加し、作成したタスクを開いて要件定義を始められるようにする。

## 追加ボタンと入力

- タスク一覧見出しの右側に「＋ タスクを追加」ボタンを表示する。タスクが0件の場合も表示する。
- ボタンを押すと、タスク名の入力欄と「作成」「キャンセル」ボタンを持つダイアログを開く。
- タスク名は必須とする。未入力または空白のみでは作成できない。

## 作成と終了時の動作

- 「作成」を押すと、入力した名前で現在開いているプロジェクトにタスクを作成する。
- 作成に成功したらダイアログを閉じ、作成したタスクを開いて要件定義を始められる状態にする。
- 「キャンセル」を押すかダイアログを閉じた場合は、タスクを作成せず元のタスク一覧に戻る。

## 処理中と失敗時の動作

- 作成処理中に「作成」を繰り返し押しても、同じ操作によるタスクの重複作成を防ぐ。
- 作成処理中は名前の入力と「キャンセル」を無効にし、Escape でも閉じない。作成結果が確定するまでダイアログを表示する。
- 作成に失敗した場合はダイアログにエラーを表示する。入力したタスク名を残し、再試行できるようにする。

## 入力範囲と既存処理

- 作成先のプロジェクトを選び直す操作は設けない。
- ユーザーが入力するのはタスク名のみとし、その他の初期値は既存のタスク作成処理に合わせる。
- 既存のタスク作成処理や共通ダイアログが利用できる場合は、この仕様を満たす形で再利用する。
