# タスク検索の仕様

## 目的

ホーム画面の検索窓から、目的のタスクを探せるようにする。タスク名が同じ場合も、タスク ID で区別する。

## 検索の方針

- Gemma の埋め込みモデルを使い、検索語と意味が近いタスクも見つけられるようにする。
- ホーム画面の検索窓から検索し、結果を確認してプロジェクト詳細画面で対象タスクのチャットを開けるようにする。
- 使用するモデルの具体的な選択や接続方法は、実装時に調べる。

## 動作の設計方針

- 検索対象はタスク ID・名前に加え、指示書や実装計画の本文とする。シークレットは対象に含めない。
- タスク ID や名前の一致と、Gemma の埋め込みによる意味の近さを組み合わせる。検索中は関連度を優先し、通常の一覧では確認待ちの優先と新しい順を使う。
- 検索結果にはタスク名・フェーズ・状態を表示し、選択すると詳細画面を開く。プロジェクトや状態での絞り込みを設ける。
- 名前や対象文書が更新されたら、検索用データの更新を予約する。更新中・失敗時には結果が古い可能性を示し、再試行できるようにする。具体的なモデルや更新方式は実装時に調べる。
