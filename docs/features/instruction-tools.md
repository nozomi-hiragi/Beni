# インストラクション編集画面のツール一覧

インストラクションを編集する人が、対象チャットで利用できるすべてのツールの名前と用途を把握し、指示に記述できるようにする。本書は合意済みの表示動作を定める。編集相談と管理画面全体の仕様は [インストラクション管理](instructions.md) を参照する。

## 実装状況と未決定事項

本書の全ツール一覧は未実装。現在の参照カードは、編集用・インストラクション・ワークフローごとの固定の埋め込みツール一覧を表示しており、エージェント提供ツールの取得や、対象チャットの条件に応じた一覧の切り替えには対応していない。

後続の技術調査では、ツール情報の取得元と更新のタイミングに加え、参照カードで対象のエージェント・フェーズ・設定をどう特定するか、取得中・取得失敗・情報を取得できない場合の表示を決定する。既存の参照タブと右側のプレビュー・編集フォーカスが独立する仕様を維持する。

## 表示するツール

- 対象チャットで実際に利用可能なツールを、漏れ・重複・利用できないツールの混入なく列挙する。
- Beni の埋め込みツールに加え、エージェントが提供するツールも含める。ファイル編集ツールは、対象チャットで利用可能な場合に表示する。
- エージェント、フェーズ、設定などで利用可能なツールが異なる場合は、それぞれの対象チャットの集合に一致させる。
- ツール情報の追加・変更を一覧へ反映する。情報の取得方法と反映方法は、後続の技術調査で決定する。

## 表示内容と並び順

各ツールは、インストラクション内で参照する名前と、実際の用途が分かる短い説明を表示する。引数・返り値の詳細表示は対象外とする。ツール名の昇順に並べ、用途別の分類は追加しない。

## 変更範囲

変更対象はツール一覧と、その表示に必要なツール情報の取得・管理とする。ツールの新設・廃止、実行権限や実行動作の変更、編集画面全体の再設計は含めない。既存のインストラクションの表示・編集・保存を維持する。

## 検証項目

| 項目 | 確認する条件 | 期待結果 |
| --- | --- | --- |
| 全ツールの網羅 | 対象チャットに実際に提供されるツールと一覧を照合する | 漏れ・重複・利用できないツールの混入がない |
| ファイル編集 | 対象チャットでファイル編集ツールが利用可能な場合を確認する | そのツールの参照名と短い用途説明が表示される |
| 内容と順序 | 各ツールの名前・用途・並びを照合する | 参照名と説明が実際の用途に一致し、名前の昇順で表示される |
| 条件による違い | エージェント・フェーズ・設定などで利用可能な集合が異なる条件を確認する | 各対象チャットの実際の集合と一覧が一致する |
| 追加・変更の反映 | 提供されるツール情報を追加・変更した場合を確認する | 一覧へ反映され、表示漏れが生じない |
| 既存機能 | インストラクションの表示・編集・保存を確認する | 引き続き利用できる |

これらは実装の合否条件であり、検証済みの結果を示すものではない。
