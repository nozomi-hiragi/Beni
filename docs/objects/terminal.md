# ターミナル

プロジェクトのフォルダーを作業場所にして、バックエンド側のシェルを操作する。一つのターミナルタブに一つのセッションが対応し、タスクを切り替えても同じシェルを使える。

## 持ち物

| 持ち物 | 数 | 用途 |
| --- | --- | --- |
| 端末画面 | 1つ | シェルの出力とカーソル位置を保持し、接続した各画面に配信する |
| 実行中のシェル | 0または1つ | 起動すると1プロセス。自然終了後はタブに端末画面と終了状態が残る |
| 操作権を持つ接続 | 0または1つ | 入力とサイズ変更を受け付ける接続。ほかの接続は同じ端末画面を閲覧できる |

## ターミナルのシェルの操作

| 操作 | 可否と操作場所 |
| --- | --- |
| 作成 | 可：プロジェクト → ターミナルの「＋」 |
| 閲覧 | 可：ターミナルタブ。複数画面から閲覧可能 |
| 更新 | 可：操作権のある画面で入力・サイズ変更。閲覧側は「乗っ取る」で操作権を取得 |
| 削除 | 可：操作権のある画面でターミナルタブの「×」を押して終了 |

画面の再読み込みや通信切断をまたいでシェルは動き続ける。複数画面で開いた場合、操作権を持つ一画面が入力できる。シェルが自然終了すると終了状態をタブで確認できる。サーバー再起動時にセッションは終了する。[ターミナルの動作仕様](../features/terminal.md)
