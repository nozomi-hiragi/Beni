# Beniが扱うオブジェクト

各ページに、その要素の役割、所属、作成・閲覧・更新・削除できる場所をまとめる。

- [プロジェクト](project.md)
- [タスク](task.md)
- [チャット](chat.md)
- [ターミナル](terminal.md)

```text
Beni
└─ プロジェクト（登録済みの作業フォルダー）
   ├─ Generalのチャット
   ├─ タスク（複数）
   │  ├─ タスクのチャット
   │  └─ タスク文書（固定3件＋追加0件以上〔資料または仕様〕）
   └─ ターミナルセッション（複数）
```

操作欄の「可」は利用者が直接操作できること、「依頼」はタスクチャットからエージェントに頼めること、「自動」は別の操作に伴ってBeniが処理すること、「不可」は対象単独の操作入口がないことを示す。
