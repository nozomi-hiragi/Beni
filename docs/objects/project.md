# プロジェクト

Beniで「プロジェクト」と呼ぶのは、ホームから登録した作業フォルダーのこと。IDと名前は `.beni/project.json` に保存し、BeniはIDと保存先パスの対応をSQLiteに記録する。

## 持ち物

| 持ち物 | 数 | 用途 |
| --- | --- | --- |
| [タスク](task.md) | 0件以上 | このプロジェクトで進める個々の依頼 |
| [ターミナル](terminal.md) | 0個以上 | このプロジェクトの作業フォルダーで使うセッション |
| ナレッジ | 0または1件 | `.beni/knowledge.md`。次のタスクに引き継ぐプロジェクト共通の学び |
| [Generalチャット](chat.md) | 1つ | プロジェクト全体の会話。各タスクの会話はそのタスクに属する |

## プロジェクトの操作

| 操作 | 可否と操作場所 |
| --- | --- |
| 作成 | 可：ホーム → プロジェクト選択 →「新規プロジェクト作成」で作業フォルダーを登録する。初回はBeniが初期化し、既存のプロジェクト情報があれば引き継ぐ |
| 閲覧 | 可：ホームのプロジェクト選択から開く |
| 更新 | 可：フォルダーを移動した後、ホームから再登録して保存先パスを更新する。画面からの改名は不可 |
| 削除 | 不可：登録の解除やフォルダーの削除を行う画面操作はない |

移動先を再登録すると、同じプロジェクトIDを引き継ぐ。

## ナレッジ

`.beni/knowledge.md` に、反省会で得たプロジェクト共通の学びを保存する。タスク固有の詳細は各タスクの `retrospective.md` に残す。次回のタスクで参照し、既存の知識を尊重して更新する。別プロジェクトへの自動共有は行わない。タスク削除では共通知識を削除せず、プロジェクトの移動では引き継ぐ。
