# チャット

プロジェクト全体の会話は `General`、個別の依頼についての会話はタスクタブで開く。Generalはプロジェクトごとに一つ、タスク会話は要件定義・仕様整理・実装手順・実装中・反省会の各フェーズに一つずつある。フェーズを戻したときは、そのフェーズの会話を再開する。履歴には発言と返信が残り、画面を開き直して読み返せる。

## 持ち物

| 持ち物 | 数 | 用途 |
| --- | --- | --- |
| 選択モデル | 0または1つ | 次の送信に使うモデルのIDと表示名。タスクではフェーズごとに保持する |
| メッセージ | 0件以上 | ユーザーの発言とエージェントの返信を記録する |
| 変更イベントのカーソル | 1つ | その会話で最後にエージェントへ渡したタスクイベントID。未送信時は未設定 |
| パック | 0個以上 | 本文やツール結果を表示・同期する単位。各パックは一つのメッセージに対応する |

最初の送信前もチャットは一つあり、履歴は空。送信すると会話履歴が保存される。

## Generalの会話の操作

| 操作 | 可否と操作場所 |
| --- | --- |
| 作成 | 自動：Generalから送信して会話履歴を作成 |
| 閲覧 | 可：プロジェクト → General |
| 更新 | 可：Generalの入力欄から発言を追加、生成中は中断可能 |
| 削除 | 不可：会話単独の削除操作なし |

## タスクの会話の操作

| 操作 | 可否と操作場所 |
| --- | --- |
| 作成 | 自動：タスクタブから送信して会話履歴を作成 |
| 閲覧 | 可：プロジェクト → 対象タスクタブの各フェーズ |
| 更新 | 可：準備フェーズ・反省会の入力欄から追加し、生成中は中断可能。実装中は停止のみ、完了中は入力不可 |
| 削除 | 自動：対象タスクの削除時に全フェーズの会話履歴も削除 |

## 個々の発言・返信の操作

| 操作 | 可否と操作場所 |
| --- | --- |
| 作成 | 可：チャットの入力欄で発言を送信。返信はエージェントが生成 |
| 閲覧 | 可：対応するチャットの履歴 |
| 更新 | 不可：送信済み発言・確定済み返信の手動編集 |
| 削除 | 不可：一件だけの削除 |

## パックの操作

| 操作 | 可否と操作場所 |
| --- | --- |
| 作成 | 自動：送信・応答・ツール呼び出しに合わせて作成 |
| 閲覧 | 可：チャット履歴に本文・ツール結果を表示 |
| 更新 | 自動：生成中に内容を追記し、区切りで確定 |
| 削除 | 不可：一件だけの削除 |

送信IDは一回の送信と応答を対応付ける。返信は表示・同期の単位であるパックに分かれ、ツール呼び出しが挟まると、その前後の本文とツール結果を別々に確定する。[会話の保存](../data/beni/chat.md)・[チャット同期](../communication/chat-sync.md)

## フェーズ間の引き継ぎ

会話履歴と接続先のセッションはフェーズごとに分ける。文書はタスク全体で共有し、次の送信時に、その会話がまだ受け取っていない変更イベントを発言と一緒にエージェントへ渡す。同じフェーズで続けて送信する場合も同じ規則を使う。時刻ではなくイベントIDで取得範囲を決める。[タスクの変更履歴](task-events.md)

## モデルの選択

モデル名は `Codex/GPT-…` のように「接続先/モデル名」で表示する。CodexとClaudeを同じ選択欄に並べ、選択は接続先とモデルIDの組で区別する。利用可能なモデル一覧はフロントエンドで共有して保持し、通常のフェーズ切り替えでは再取得しない。選択はフェーズごとにフロントエンドで記憶し、切り替え時はその選択をすぐ復元する。未選択の場合だけ一覧の先頭を初期選択する。

選択モデルが一覧にない場合や送信時に利用不可と判明した場合は、モデル名に `⚠️` を付けてそのチャットの送信を無効にする。この選択を持つフェーズへ切り替えたときは、利用可能なモデル一覧を再同期する。別のモデルへ自動変更しない。有効なモデルへの選び直し、または再同期による利用可能状態の確認で操作を再開する。

モデルの選択だけではバックエンドへ保存要求を送らない。メッセージ送信時に本文と選択モデルを一緒に送り、バックエンドでは受け付けたモデルを会話に保存する。フロントエンドに選択がない場合は、この保存済みのモデルを復元に使う。過去の発言の使用モデルは変更しない。

モデル利用不可で送信できなかった場合は、送信内容を入力欄へ戻す。送信中に追記した内容も保持し、自動再送はしない。通常の通信失敗や結果不明をモデル利用不可と決めつけない。応答生成中はモデルを変更できず、処理の終了後に次の送信で使うモデルを選ぶ。

実装担当モデルはタスク単位の別選択とし、チャットのモデル変更では変わらない。実装開始時はそのモデルを実装中の会話へ渡す。実装中・完了中は入力欄とチャット用モデル選択を表示しない。
