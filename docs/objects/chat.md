# チャット

プロジェクト全体の会話は `General`、個別の依頼についての会話はタスクタブで開く。Generalはプロジェクトごとに一つ、タスク会話はタスクごとに一つある。履歴には発言と返信が残り、画面を開き直して読み返せる。

## 持ち物

| 持ち物 | 数 | 用途 |
| --- | --- | --- |
| メッセージ | 0件以上 | ユーザーの発言とエージェントの返信を記録する |
| パック | 0個以上 | 本文やツール結果を表示・同期する単位。各パックは一つのメッセージに対応する |

最初の送信前もチャットは一つあり、履歴は空。送信すると会話履歴が保存される。

## Generalの会話の操作

| 操作 | 可否と操作場所 |
| --- | --- |
| 作成 | 自動：Generalから送信して会話履歴を作成 |
| 閲覧 | 可：プロジェクト → General |
| 更新 | 可：Generalの入力欄から発言を追加、生成中は中断可能 |
| 削除 | 不可：会話単独の削除操作なし |

## タスクの会話の操作

| 操作 | 可否と操作場所 |
| --- | --- |
| 作成 | 自動：タスクタブから送信して会話履歴を作成 |
| 閲覧 | 可：プロジェクト → 対象タスクタブ |
| 更新 | 可：タスクタブの入力欄から発言を追加、生成中は中断可能 |
| 削除 | 自動：対象タスクの削除時に会話履歴も削除 |

## 個々の発言・返信の操作

| 操作 | 可否と操作場所 |
| --- | --- |
| 作成 | 可：チャットの入力欄で発言を送信。返信はエージェントが生成 |
| 閲覧 | 可：対応するチャットの履歴 |
| 更新 | 不可：送信済み発言・確定済み返信の手動編集 |
| 削除 | 不可：一件だけの削除 |

## パックの操作

| 操作 | 可否と操作場所 |
| --- | --- |
| 作成 | 自動：送信・応答・ツール呼び出しに合わせて作成 |
| 閲覧 | 可：チャット履歴に本文・ツール結果を表示 |
| 更新 | 自動：生成中に内容を追記し、区切りで確定 |
| 削除 | 不可：一件だけの削除 |

送信IDは一回の送信と応答を対応付ける。返信は表示・同期の単位であるパックに分かれ、ツール呼び出しが挟まると、その前後の本文とツール結果を別々に確定する。[会話の保存](../data/beni/chat.md)・[チャット同期](../communication/chat-sync.md)
