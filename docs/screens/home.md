# ホーム画面

## 目的

タスクを一覧して状況を確認し、新しいタスクを作成したり、各タスクのチャットを開いたりする。

ホームの URL は `/` とする。

## 画面の配置

上部にメニューバーを置き、左側に「Beni」、右側に LLM の利用枠、検索窓、設定ボタンをこの順に置く。その下の中央にタスク追加の領域を配置し、さらに下の広い領域にタスク一覧を表示する。

## 表示・操作

- ホーム画面にタスク名の入力欄と「タスク作成」ボタンを表示し、その近くにプロジェクト選択のプルダウンを置く。
- プルダウンには既存プロジェクトと「新規プロジェクト作成」を表示する。新規作成を選ぶと、プロジェクト作成ダイアログを開く。
- タスクを一覧表示し、各タスクの ID、名前、現在のフェーズ、回答待ち・処理中などの状態を表示する。
- 一覧に ID・タスク名・フェーズ・状態の見出し行を置く。見出しを押すたびにその列の昇順・降順を切り替える。最後に押した列を優先し、同じ値のタスクは直前の並び順を保つ。たとえば、先に ID 順、次に状態順を選んだ場合、同じ状態の中では ID 順が保たれる。初期表示は確認待ちなどユーザーの対応が必要なタスクを優先し、その中では新しい順に並べる。
- タスク検索用の検索窓を設け、Gemma の埋め込みモデルを使って意味が近いタスクも検索できるようにする。
- タスクを選ぶと、プロジェクト詳細画面でそのタスクのチャットを開く。
- 連携している LLM の利用枠を確認できるようにする。取得できる情報は接続先によって異なるため、利用枠を確認できない場合はその旨を表示する。
- タスク名が未入力、またはプロジェクトが未選択の場合は「タスク作成」を押せない。両方そろったときに押せる。
- ユーザーがタスク名を入力して「タスク作成」を押すと、タスクを作成し、タスク名をもとに指示書の Markdown 作成を始め、プロジェクト詳細画面を開き、作成したタスクのチャットを表示する。
- タスクには連番の ID を付けて区別する。タスク名の重複は許可する。
- タスクの作成後、プロジェクト詳細画面のタスクチャットで希望を伝えていく。

## 表示の設計方針

- 状態は「処理中」「回答待ち」「確認待ち」「停止中」「エラー」「完了」を表示する。初期表示では、回答待ち・確認待ち・ユーザーの対応が必要なエラーを上に表示し、それぞれ新しいタスクから並べる。
- 利用枠は接続先ごとに、取得できた残量や更新予定時刻を表示する。取得できない場合は「未取得」「取得できない」など実際の状態を表示し、更新失敗時は前回取得時刻を示す。接続先ごとの取得方法は実装時に確認する。
- 検索の詳細は[タスク検索の仕様](../features/task-search.md)を参照。
