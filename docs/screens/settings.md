# 設定画面

共通ヘッダーの右端にある設定ボタンから開く。ホームへ戻るボタンからホームに戻れる。

設定画面の URL は `/settings` とする。再読み込みしても設定画面を開き、ブラウザーの戻る・進む操作で画面を移動できる。

## LLM の接続

Codex と Claude Code の接続状態を表示する。ユーザーはサーバーの実行環境に CLI をインストールし、CLI でログインする。

- 実行環境で CLI を検出し、インストール済みかとログイン済みかを別々に表示する。検出した実行ファイルとバージョン、確認日時も確認できるようにする。
- 未インストールならインストールを、未ログインなら「Claude Code にログインしてください」「Codex にログインしてください」と案内する。Beni 内にログイン操作や資格情報の入力欄は設けない。
- 「更新」ボタンでインストール・ログイン状態を再確認し、利用枠を取り直す。確認中は二重操作を防ぐ。Claude Code の利用枠取得では、一時セッションで短い推論リクエストを送る場合がある。
- ログインに使われている認証方式を確認できる場合は表示し、API キー利用をサブスク利用と混同しない。モデル・利用枠は取得できる範囲を表示し、取得できない項目は未確認とする。ログイン済みだけで特定モデルの利用可能性を保証しない。

詳細は [LLM チャット連携](../features/llm-chat.md)を参照する。
