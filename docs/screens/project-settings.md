# プロジェクトの登録と作業場所

## プロジェクト作成

- ホームのプロジェクト選択プルダウンから「新規プロジェクト作成」を選ぶと、作成ダイアログを開く。
- ダイアログでプロジェクト名とサーバー上の作業フォルダーを絶対パスで指定する。「参照」からサーバー上のフォルダーを選べる。
- 作成後はダイアログを閉じ、ホームで登録したプロジェクトを選択済みにする。入力途中のタスク名は、作成した場合も取り消した場合も保持する。
- 一つのタスクは一つのプロジェクトに属する。

## プロジェクト詳細・セットアップ

ホームでプロジェクトを選び「プロジェクトを開く」を押すと、プロジェクト詳細の General チャットを開く。General では作業フォルダーを読み取り専用で調査できる。リモートリポジトリのクローンなどのセットアップは、同じ画面のターミナルから実行できる。タスクの実装中・反省会では、接続先の実行制限の範囲で作業フォルダーの編集を依頼できる。

フォルダー移動時の再登録とプロジェクト名の扱いは [プロジェクトの操作](../objects/project.md#プロジェクトの操作) を参照。
