# プロジェクトの登録と作業場所

Beni の保存データと、エージェントが作業するフォルダーを別々に管理します。[保存構成](../data/storage.md)

## プロジェクト作成

- ホームのプロジェクト選択プルダウンから「新規プロジェクト作成」を選ぶと、作成ダイアログを開く。
- ダイアログでプロジェクト名とサーバー上の作業フォルダーを絶対パスで指定する。「参照」からサーバー上のフォルダーを選べる。
- 作成後はダイアログを閉じ、ホームで登録したプロジェクトを選択済みにする。入力途中のタスク名は、作成した場合も取り消した場合も保持する。
- 一つのタスクは一つのプロジェクトに属する。

## プロジェクト詳細・セットアップ

ホームでプロジェクトを選び「プロジェクトを開く」を押すと、プロジェクト詳細の General チャットを開く。General では作業フォルダーを読み取り専用で調査できる。リモートリポジトリのクローンなどのセットアップは、同じ画面のターミナルから実行できる。タスクの実装中・反省会では、接続先の実行制限の範囲で作業フォルダーの編集を依頼できる。

## 作業フォルダーの変更

ホームでプロジェクトを選び「作業フォルダーを変更」を押すと、現在の登録先を入力済みのダイアログを開く。「参照」からフォルダーを選び、保存すると同じプロジェクトIDに新しい作業先を対応付ける。実行中のプロジェクトや、別プロジェクトが登録済みのフォルダーには変更できない。

作業フォルダーの不在や移行エラーはホームに表示する。移行済みデータの閲覧は継続できるが、作業フォルダーを使う実行は再指定まで開始できない。保存失敗時はダイアログ内にエラーを表示し、入力を保持する。

フォルダー変更時の識別子とプロジェクト名の扱いは [プロジェクトの操作](../objects/project.md#プロジェクトの操作) を参照。
