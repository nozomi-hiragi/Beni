# プロジェクト設定

## プロジェクト作成

- ホームのプロジェクト選択プルダウンから「新規プロジェクト作成」を選ぶと、作成ダイアログを開く。
- ダイアログではアプリ上のプロジェクト名とフォルダを指定する。フォルダ欄の横に、選択ダイアログを開く「参照」ボタンを置く。
- 作成後はホームに戻り、作成したプロジェクトを選択済みにする。入力途中のタスク名も保持する。取り消した場合もタスク名を保持する。
- 最初は一つのタスクに一つのプロジェクトを選ぶ案。複数プロジェクトの扱いは必要に応じて検討する。

## プロジェクト詳細・セットアップ

プロジェクト詳細画面を共通の作業画面として使う。上部にメニューバーと名前、作業領域の左にチャット、右にプレビューを並べ、それぞれ上部にタブを置く。チャットの下にターミナルを置く。チャットの左にタスクツリー、プレビューの左にファイルツリーの開閉ボタンを固定し、それぞれタブ部分を横スクロールできる。チャットにはタスクに対応するものと、対応しないジェネラルなものがある。

- プロジェクト詳細画面にチャット欄を設け、ユーザーが会話でプロジェクトのセットアップを依頼できるようにする。
- たとえばリポジトリの URL を渡してクローンを頼んだり、ゼロから Git の初期化を頼んだりする。
- セットアップの進捗や結果をチャットで確認できるようにする。
- プレビュー内でファイルツリーを開き、選択したファイルをプレビュー領域で表示する。プレビューはタブで切り替える。
- プロジェクト詳細に、作業場所で直接コマンドを実行して出力を確認できるターミナルを設ける。タスクごとの作業場所との関係は検討する。
