# .beni/chat の会話

実装後も残す仕様のたたき台です。現行形式と未決事項は [会話の移行](migration.md#会話の移行) に分けます。

会話はバックエンドで永続化し、プロジェクトのジェネラル会話とタスクごとの会話を区別します。JSONは人が直接開いて確認できる形式とします。

発言、送信状態、順序付きのパック列、接続先の会話識別子を保持します。送信ID・パックID・CLI側のセッションIDは用途を分けます。

バックエンドに保存した内容を正本とし、フロントエンドの受信内容はパック単位の照合後に確定します。完了を確認できない送信は自動再送しません。

会話はジェネラル・タスク会話とも対象プロジェクト直下の `.beni` に配置します。ジェネラルは `chat/general.json`、タスク会話は `chat/<taskId>.json` に保存します。`taskId` は [共通ID規則](../README.md#idの共通規則) に従い、タスク情報と同じIDを使います。会話を公開リポジトリへ自動追加しません。

保存・更新の契約は [LLMチャット](../../features/llm-chat.md#チャット履歴の保存)、パックの形式と同期は [通信仕様](../../communication/chat-sync.md) を参照します。
