# Beni

複数のコーディングエージェントを使い、依頼から計画・実行・監修までを支援するアプリケーションです。

## 起動

[Bun](https://bun.sh/) を用意して、このディレクトリで実行します。

```sh
bun install
bun run start
```

起動時に SolidJS の TypeScript と Tailwind CSS・daisyUI のスタイルをビルドします。

ブラウザーで http://127.0.0.1:3210/ を開きます。ポートは `BENI_PORT` で変更できます。

## データの保存先

Beni 自身のデータは、起動した作業ディレクトリにかかわらず、Beni のルートにある `data/` へ保存します。このフォルダーは Git 管理の対象外です。

```text
data/
  beni.sqlite
  chat/
```

`BENI_DATA_DIR` で保存先フォルダーを変更できます。相対パスを指定した場合は、起動時の作業ディレクトリを基準にします。会話は平文で保存されるので、秘密情報を入力しないでください。

DB と会話は同じ保存先フォルダーにまとめます。個別の保存先設定は廃止しました。

以前のデータは自動では移動しません。引き継ぐ場合は Beni を停止してバックアップを取り、指定した保存先フォルダーへ DB と関連ファイルを移し、会話フォルダーを `chat/` として配置してください。DB の名前は `beni.sqlite` に揃えます。

## 現在の機能

プロジェクトの名前とフォルダの登録、タスク作成、タスク別の会話保存、初期指示書の表示に対応しています。フォルダの登録はパスの記録のみです。タスクの指示書は名前から初期化し、会話からの自動更新はまだ行いません。

LLM、認証、利用枠、計画・実行、ターミナル、Gemma を使った検索は未接続です。検索は現在、タスク名と ID の簡易検索です。
